# OpenAPI specification

The Relay API is described in an [OpenAPI 3.1 specification](openapi.yaml).
The reference pages on this site are generated from it, so the two always
match.

Use the specification to:

- Generate a client library in your programming language.
- Import the API into a tool such as Postman or Insomnia.
- Give an AI assistant the exact operations, parameters, and fields, so it
  doesn't have to guess.

Every operation, parameter, and field in the specification has a
description, and every request and response has an example. An automated
check enforces both on every change.
